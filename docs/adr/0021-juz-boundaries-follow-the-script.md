# Juz boundaries follow the Script

Readers know a Juz by its traditional name (سَيَقُولُ, وَمَا لِيَ), but those names come from the Indo-Pak Para tradition, where a Para ends where a Ruku ends, while QUL's Juz file follows the Madinah mushaf. The two disagree on where seven Juz start (4, 7, 11, 14, 20, 21, 23; e.g. Juz 23 at 36:22 in Indo-Pak, 36:28 in Madinah). So the Juz follow the reader's Script, as each mushaf prints them: Uthmani readers get the Madinah Juz, named by their opening words, which keeps them in step with the Hizb quarter Section marks drawn from the same mushaf; Indo-Pak readers get the Indo-Pak Juz with their traditional names. A Juz link or Reading-place dot can therefore point at a different Ayah for two readers of the same Juz number.

## Considered Options

- Madinah Juz for everyone with the traditional names: rejected because seven names would sit up to six Ayahs away from where their Juz opens.
- Indo-Pak Juz for everyone: rejected because Uthmani readers' Juz would no longer begin at a Hizb quarter of their own mushaf.

## Consequences

- Saaliheen needs an Indo-Pak Juz source beside QUL's Madinah file, and the 30 traditional names, which are kept as Saaliheen's own data.
